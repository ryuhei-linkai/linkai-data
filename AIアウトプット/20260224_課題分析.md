## 1. 根本原因の構造

元の課題メモを分析すると、表面的には多岐にわたる課題が並んでいるが、根本原因は3つに集約される。

```
┌─────────────────────────────────────────────────────┐
│            根本原因 A: 代表ボトルネック               │
│   全領域に代表が関与 → 全体が見きれない → 課題が乱発   │
└──────────────┬──────────────────────────────────────┘
               │ 時間がない
               ▼
┌─────────────────────────────────────────────────────┐
│            根本原因 B: 定義不足                       │
│   人材要件・プラン・価格・必要資金額が全て未定義        │
└──────────────┬──────────────────────────────────────┘
               │ 定義がないから仕組みにできない
               ▼
┌─────────────────────────────────────────────────────┐
│            根本原因 C: 仕組み化不足                   │
│   案件管理・代理店契約・コーポレート業務が属人的        │
└──────────────┬──────────────────────────────────────┘
               │ 仕組みがないから代表に集中
               ▼
            （Aに戻る＝悪循環）
```

この3つは悪循環を形成しており、どこか1つを断ち切らないと全体が改善しない。

## 2. 課題の論点整理（6領域）

### 論点1: 代表の時間配分と権限委譲

**現状から読み取れること:**
- 安東氏がSUISHIN開発(30h/週)＋複数クライアント案件＋営業＋全社戦略を同時に担当
- VINATECH（月137万円の大型案件）に張り付けないが、代替人材の要件定義もできていない
- JBCI(ACN)の現場も安東・徳梅が抜けて手薄化
- 戦略策定（プラン設計、代理店設計、資金調達）に集中する時間が取れない

**本質的な問い:** 安東氏の時間を「何に使い、何から外れるか」を決めること自体が最大の経営判断

---

### 論点2: ソリューション案件の人材課題

**現状から読み取れること:** 複数案件で人材不足が同時発生している

| 案件 | 不足人材 | 緊急度 | 難易度 |
|------|---------|--------|--------|
| レント（3月開始） | 開発者1名 | 今すぐ | 中（AIアバター開発） |
| VINATECH キャパシタ（3月開始） | AI＋製造業アドバイザー | 今すぐ | 高（キャパシタ×AI の専門性） |
| VINATECH データ整備 | 未定義 | 中 | 案件解像度が低い |
| JBCI(ACN) 現場強化 | 開発者1名 | 中 | 中 |
| 東京スミセイ | エンジニア3人月 | 未確定 | 中 |

**共通する構造:**
- 「どんな人材がどれくらい必要か」の要件定義ができていない（特にVINATECH）
- 案件の解像度を上げる作業自体に代表の時間が必要だが、その時間がない（→論点1に戻る）
- 受注の確度・タイミングが読めないため、先行して人材を確保しにくい

---

### 論点3: SUISHINのプロダクト戦略

**現状から読み取れること:**
- 3つのプラン案（サブスク/ソリューション/コンサル）があるが未決定
- 価格設定が未定 → 代理店が売れない、営業が動けない
- モジュール構成は構想段階 →「SUISHIN FOR X」の実現可否が不明
- カトルセ経由ですでにトムソン(A:80%)、関西テレビ(B:50%)のパイプラインが生まれている
- 3月から展示会が始まるが、そこで何をいくらで売るかの定義が必要

---

### 論点4: 営業・代理店戦略

**現状から読み取れること:**
- 4社の代理店候補がいるが、契約・プラン・マージン設計が未整備
- カトルセは実績があるが契約が体系化されていない
- HTSは「費用とプランがわかれば提案できる」と言っている → プラン定義待ち
- 2025年の売上エンジンは展示会。2026年は独自出展4回＋SUISHINプロダクト販売
- 展示会で売れた案件をデリバリーする体制との同時並行が必要

**決めないと動かないこと:**
1. SUISHINの値付け・プラン体系
2. 代理店マージン設計
3. 代理店 vs 直販の棲み分けルール
4. 代理店向けの販売ツール・デモ環境

---

### 論点5: 資金・資本戦略

**現状から読み取れること:**
- 債務超過 -1,159万円だが、月次黒字化しており2025年通年で+1,389万の純CF
- 手元現金222万円。売掛金576万の回収タイミング次第でCFが変動
- 確定済み売上だけで見ると10〜12月は月194万に減少するが、展示会・営業はこれから
- ボンギンカン40%保有（40万円で取得）→ エクイティ調達時の制約
- 資金調達方針（デット/エクイティ）が未決定。必要金額の算出に必要な人材要件定義が未完了

**構造的な循環:**
```
人材要件を定義したい → 事業計画が必要 → 売上予測が必要
→ プラン・価格が未定 → 代理店が動けない → 売上が読めない
→ 必要資金がわからない → 調達できない → 人材を採れない
→ (最初に戻る)
```

## 3. 推奨アクション

悪循環を断ち切る最も現実的な起点は「定義不足の解消」（根本原因B）。
全てを一度に定義するのは不可能なので、波及効果が最大のものから順に進める。

### Phase 1: 今すぐ（〜3月上旬）— 3月展示会・3月開始案件に間に合わせる

| # | アクション | 理由 | 所要時間目安 |
|---|---|---|---|
| 1-1 | レント案件の1名確保 | 3月開始。徳梅に採用条件を具体化してもらい候補リストを出す | 1週間 |
| 1-2 | VINATECH案件の要件整理 | 月137万の大型案件。案件の解像度を上げ、必要な人材像を文書化する | 安東2-3時間の集中作業 |
| 1-3 | SUISHINの展示会用プラン・価格を「仮決め」する | 3月展示会で売るために必須。完璧を目指さず提示できるレベルで仮設定 | 安東の意思決定 |
| 1-4 | 展示会後に案件を受けられる体制の確認 | 売れても受けられないと機会損失。最低限のデリバリーフローを整理 | 徳梅と1時間の打ち合わせ |

### Phase 2: 3〜5月 — 展示会で売る＋体制を整える（同時並行）

| # | アクション | 理由 |
|---|---|---|
| 2-1 | 展示会3回（3月・4月・5月）でSUISHIN＋ソリューションを営業 | 2025年の売上エンジンが展示会だった実績に基づく。Link AI独自出展の初年度 |
| 2-2 | 代理店契約のテンプレートを作成 | カトルセとの関係を正式契約化。マージン率・責任範囲を明文化。HTS・Asetsにも展開 |
| 2-3 | 案件別の人材要件一覧を作成 | 全案件横断で「いつ・どんなスキル・何名」を一覧化 → 採用の優先順位が見える |
| 2-4 | カトルセ経由パイプライン（トムソン・関西テレビ）の受注確定 | CF予測に未計上の案件。SUISHIN初の実導入事例にもなり得る |
| 2-5 | NTTテクノクロス・SLCの売上見込みをCF予測に反映 | 進行中案件を正確に数字に落とし、資金計画の精度を上げる |
| 2-6 | 3月展示会の結果を踏まえてCF予測を更新 | 展示会の反応で下半期の売上見通しが変わるため |

### Phase 3: 6月以降 — スケールの仕組み化

| # | アクション | 理由 |
|---|---|---|
| 3-1 | 人材要件一覧をベースに必要資金を算出 | → 資金調達（デット or エクイティ）の方針決定 |
| 3-2 | 案件管理・人員管理の仕組み構築 | SUISHIN or 別ツールで情報を一元管理 |
| 3-3 | JBCI(ACN)のCRM移行案件の提案書作成 | アップセル機会を逃さない。下半期の継続売上にもなる |
| 3-4 | 展示会・営業で得た案件の安定デリバリー体制確立 | 「売れる→受ける→納品する→実績になる→次が売れる」のサイクルを回す |
