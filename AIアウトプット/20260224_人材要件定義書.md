## 1. 直面している事業課題（人材起因のもの）サマリー

### 1.1 全体像

Link AIは**SUISHINプロダクト**と**ソリューション案件**の2軸で成長フェーズに入っているが、**人材定義が未完了**のまま案件・プロダクトが先行し、以下の人材起因課題が顕在化している。

| 領域 | 人材起因の課題 | 緊急度 | 影響 |
|------|---------------|--------|------|
| **ソリューション案件** | 個別案件へのアサイン不足。レント1名欠、VINATECH代替人材不在、ACN現場手薄 | 高 | 納期・品質リスク、代表の過負荷 |
| **ACN（最大クライアント）** | 安東・徳梅が経営/統括にシフトし現場が手薄。CRM移行のアップセル体制も未整備 | 高 | 最大売上源のリスク |
| **VINATECH** | 月2回韓国訪問＋月8回MTG（1回4h）のアドバイザリー人材が代表以外にいない。キャパシタ＋AI両方わかる人材の定義・確保が未着手 | 高 | 4月開始予定の約1,370万/月契約が危険 |
| **レント** | 3月スタートのAIアバター開発で1名が急遽確保できなくなった | 高 | 3月からの稼働体制が不足 |
| **SUISHIN開発** | Skillsを理解・構築できるコアエンジニア不在。代表30h/週がほぼ全投入 | 高 | プロダクト推進が代表依存でボトルネック |
| **営業体制** | SUISHIN＋ソリューション両方を売れるオールマイティ（FDE型）人材不在 | 中 | 代理店・直販の拡大が進まない |
| **データ整備・エージェント構築** | ソリューション提案に必要な「データ整備＋エージェント構築」スキルを持つ人材が不足 | 中 | カトルセ経由のトムソン・関西テレビなどの受注準備が遅延 |
| **資金調達** | 人材要件が未定義のため調達額・調達手法が決められない | 高 | 資本戦略が停滞 |

## 4. 正社員 vs 業務委託の推奨方針

### 4.1 代表の悩みへの回答

**代表の懸念（課題メモより）:**
- 正社員を雇ったことがないためメリットがわからない
- 正社員への規制が厳しく、フリーランスの方がゴリゴリ働けるのでは？
- 正社員を増やしても生産性が上がらないのでは？

### 4.2 推奨方針

#### （1）当面は「業務委託をベースに、特定ポジションのみ正社員候補」で進める

**理由:**
- 現状の資金・組織規模では、いきなり正社員を複数雇うリスクが大きい
- 案件の変動（紹介・単発受注ベース）が依然として大きく、固定費の増加は負荷になる
- 業務委託なら稼働に応じた柔軟なスケールが可能

#### （2）正社員化を検討すべきポジション

| ポジション | 正社員候補とすべき理由 | タイミング |
|-----------|------------------------|-----------|
| **D（SUISHIN技術PM）** | プロダクトの思想・Skills・アーキテクチャを継承する「コア」。 turnoverされるとプロダクトの継続性が危ぶまれる | 採用後6〜12ヶ月で実績を確認し、中長期的なコミットを要請する場合 |
| **F（営業×技術）** | 顧客関係・商習慣の蓄積。代理店・直販の窓口として安定した顔が必要 | 代理店契約が複数締結し、営業体制が固定化した段階 |
| **徳梅氏** | すでに開発統括・PMとして中核。正式な責任範囲とコミットを明確にしたい場合 | 経営判断による。現状は業務委託でも実質的にコミット済み |

#### （3）業務委託のままがよいポジション

| ポジション | 理由 |
|-----------|------|
| **A（VINATECHアドバイザー）** | 案件期間が1年程度。キャパシタ×AIという特殊スキル。契約終了後の継続性より、期間中の質が重要 |
| **B（レント用エンジニア）** | 案件は3月〜8月の6ヶ月。終了後の再アサインが不透明 |
| **E（データ整備×エージェント）** | 案件単位のアサインが中心。複数案件をまたぐ場合は業務委託の柔軟性が有効 |
| **G（デザイン/UX）** | プロジェクト単位での発注が現実的 |

#### （4）正社員のメリットを「限定して」使う

正社員のメリットは主に次の3点に集約できる：
1. **中長期コミット**：プロダクト・顧客関係を継承しやすい
2. **採用・ブランディング**：「正社員」というメッセージが求人に与える効果
3. **経営との距離**：意思決定や情報共有が密になる

逆に、**単純に「がんばってほしい」という期待で正社員にすることは推奨しない**。業務委託でも十分コミットする人はいる。まずは業務委託で実績・相性を確認し、**「この人といなくては回らない」というポジションに限定して正社員化を検討**するのが現実的。

### 4.3 まとめ（方針サマリー）

| フェーズ | 方針 |
|---------|------|
| **直近〜半年** | 新規は基本的に業務委託で採用。A/B/C/Eを優先して確保 |
| **半年〜1年** | D（SUISHIN技術PM）が定着したら、正社員化の検討を開始。資金・売上見通しと連動 |
| **営業体制確立後** | F（営業×技術）を正社員候補として位置づけ、採用検討 |
| **全般** | 「正社員か業務委託か」より、「誰をどの案件/プロダクトにどうアサインするか」の設計を優先する |
