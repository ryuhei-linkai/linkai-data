## 1. 現状分析：データが語っていること

### アカウント概況
- **フォロワー:** 約3,300人
- **投稿数（過去1年）:** 1,602件
- **10K imp超え投稿:** 45件（全体の2.8%）
- **最大インプレッション:** 504,916（Chrome MCP速報）

### 明確なパターン：「投稿頻度」と「バズ率」は比例しない

| 月 | 投稿数 | バズ率 | 実態 |
|---|---|---|---|
| 2025-07 | 306件 | 0.3% | 量は最大だがバズ率最低 |
| 2025-10 | 141件 | 6.4% | 量は半分以下だがバズ率最高 |
| 2025-05 | 218件 | 4.6% | 量・質ともに高い黄金期 |

**結論：量を追うフェーズは終わった。「打率を上げる」フェーズに入るべき。**

### バズった投稿の共通点（10K imp超え 45件の分析）

1. **速報×構造化 = 最強の型**
   - Chrome MCP（50万imp）、Microsoft Office Agent（23万imp）、Google Opal（13万imp）
   - 新ツール・新発表を「何がすごいのか」「つまりどうなるのか」付きで即座に出す
   - メディアやリンクを含む投稿が60%

2. **キーワードの勝ちパターン**
   - MCP（8回）、エージェント（7回）、Cursor/Gemini/Google/Manus/ワークフロー（各5回）
   - 「ツールの名前 × ビジネスインパクト」の掛け合わせが最も伸びる

3. **テキスト長と質の関係**
   - バズ投稿の平均テキスト長：100文字（通常の64文字の1.5倍）
   - 短すぎず、長すぎない「1ツイートに収まる濃い情報」が最適解

4. **曜日別パフォーマンス**
   - 日曜（avg 4,572 imp）と金曜（avg 3,518 imp）がベスト
   - 週末は競合の投稿が減り、ビジネスパーソンの「キャッチアップ時間」と重なる

### フォロワー成長の急カーブ

| 期間 | 月次フォロワー増（net） | 要因 |
|---|---|---|
| 2025-03〜05 | +198〜+286/月 | 積極的な投稿開始期 |
| 2025-10 | **+678/月** | 超バズ月（Oct 5-8に連続大ヒット） |
| 2025-11〜2026-03 | -3〜+11/月 | **ほぼ停止** |

**直近4ヶ月で成長が完全に止まっている。発信再開は「今」がタイムリミット。**

## 2. 発信コンセプト

### ポジション定義

```
「AIの社会実装を、プロダクトとソリューションの両面で現場に届ける実務家」
```

このポジションが刺さる理由：
- AI系インフルエンサーは「技術者」か「情報キュレーター」に二極化している
- 安東さんは「自分でプロダクトを作りながら、企業にAIを入れている」という両方を持つ稀有な立場
- しかもClaude Code/MCPを使った開発実践を日常的にやっている＝実践の裏付けがある

### コンセプト名

```
「AI実装者の視点」
```

- 評論家でもなく、エンジニアでもなく、「実装者（Implementer）」
- 情報を追うだけでなく、実際に企業に入れている・自分のプロダクトで使っている
- この立場からの発信は、AI推進担当や経営者にとって「リアルな参考」になる

### 3本柱

| 柱 | 内容 | 目的 | 配分 |
|---|---|---|---|
| **① 速報＋洞察** | AI新ツール・発表を「ビジネスインパクト」付きで速報 | リーチ拡大・フォロワー獲得 | 50% |
| **② 実装の現場から** | SUISHIN開発、企業AI導入の実体験・気づき | 権威性・信頼の構築 | 30% |
| **③ フレームワーク提唱** | AIエージェントファースト組織、業務AI化の新概念 | 思想的リーダーシップ | 20% |

## 3. 具体的な投稿設計

### 柱①：速報＋洞察（週3-4本）

**これが「入口」。新規フォロワーはほぼここから来る。**

構造：
```
[ツール/発表名] + [感情的な一言]

[何がすごいか 2-3行]

つまり、[ビジネスへのインパクトを一言で]

[スクショ or リンク]
```

実績からの勝ちパターン：
- 「Chrome MCP来た」→ 50万imp（速報＋構造化リスト）
- 「Office Agent ヤバい」→ 23万imp（感嘆＋業界インパクト）
- 「LINE公式MCPキタ！」→ 10万imp（超シンプル速報＋画像）

ポイント：
- **速さが命。発表から30分以内に出す**
- ただの転載ではなく「つまりこれが意味するのは〜」を必ず付ける
- スクショ or デモ画像があるとインプレッション2-3倍

### 柱②：実装の現場から（週2本）

**これが「権威」を作る。安東さんにしか書けない内容。**

パターンA：SUISHIN開発の裏側
```
SUISHINの[機能名]を作ってて気づいたんだけど、

[開発中の発見・課題]

結局、[本質的な気づき]

プロダクト作りながら思うのは、[示唆]
```

パターンB：クライアント案件の気づき（匿名・抽象化）
```
とある企業でAI導入を進めてるんだけど、

[ぶつかった壁・意外な発見]

[教訓・パターン]

[読者への問いかけ]
```

パターンC：ツールの実践レポート
```
[ツール名]を実業務で2週間使ってみた感想：

良い点：
・[具体]
・[具体]

微妙な点：
・[具体]

結論：[率直な評価]
```

過去の成功例：
- 「Cursor使ってたときは〜Claude Codeに移った」→ 33,453 imp（実体験の移行記）
- 「やっぱ資料はClaudeだなあ」→ 75,205 imp（使ってみた系）
- 「AIエージェントが働きやすい職場」→ 12,028 imp（自社実践の概念化）

### 柱③：フレームワーク提唱（週1本）

**これが「思想的リーダー」を作る。最も拡散されやすく、ブックマークが多い。**

構造：
```
[新しい概念名]が重要なのではないかと思ってきた。

[背景・なぜ今か]

[概念の定義]

[メカニズム・なぜ機能するか]

[具体例]

だから[結論]
```

安東さんのビジネスから生まれる概念候補：
- **「AIエージェントファースト組織」** — AIが働きやすい環境づくりが人間も働きやすくする
- **「プロジェクト推進AI」** — タスク代替ではなく成果を出すためのAI活用
- **「AI実装の3層構造」** — ツール選定 < 業務設計 < 組織変革
- **「巻き込まない力」** — AI導入は全社推進より「気づいたら変わってた」が正解
- **「SUISHIN FOR X」的思考** — 汎用AIより業界特化AIの方が刺さる理由

過去の成功例：
- 「生成AI導入って巻き込まない力が必須かも」→ 高エンゲージメント
- 「AIエージェントが働きやすい職場」→ 12K imp、like率1.16%（トップ級）

## 4. 運用ルール

### 投稿頻度

```
目標：週6-7本（1日1本ペース）
内訳：速報3-4本 + 実装2本 + 概念1本
```

なぜこの頻度か：
- 2025年5月（218本/月≒7本/日）は量多すぎてバズ率低下
- 2025年10月（141本/月≒5本/日）が最も効率的だった
- ただし10月は大型ニュースが重なったので、平常時は1日1本が現実的

### 投稿タイミング

| 優先 | 曜日 | 時間帯 |
|---|---|---|
| 最優先 | 日曜 | 朝8-10時（キャッチアップ時間） |
| 高 | 金曜 | 夜19-21時（週末前のSNSタイム） |
| 中 | 火曜 | 昼12-13時（ランチタイム） |

### 速報のスピードルール

```
大型発表（Google/OpenAI/Microsoft/Anthropic）
→ 30分以内に第一報
→ 1時間以内に構造化解説
→ 翌日にフォローアップ（使ってみた、深掘り）
```

### やめること

- **リプライ・引用RTの乱発**（2025年後半に多かった。自分のTLが薄まる）
- **感想だけの投稿**（「すごい」「ヤバい」だけでは権威は作れない）
- **1日5本以上の投稿**（フォロワーのTLを占拠するとアンフォローされる）

### 続けること

- **スクショ・画像の添付**（バズ投稿の60%にメディアあり）
- **「つまり〜」の洞察**（これがない投稿は伸びない）
- **人間味のある言い回し**（「うーん」「ぶっちゃけ」「やっぱ」）
