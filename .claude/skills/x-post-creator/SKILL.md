# X Post Creator for AI Content

## 概要

企業のAI推進担当・経営者向けに、AIの最新動向と洞察を届けるXポストを作成するスキル。

**ターゲット読者の心理**
- AIキャッチアップできているか不安→最新情報で安心したい
- 時間がない→要点を素早く理解したい
- 使いたいけど確証がない→実践の裏付けが欲しい

**提供価値**
- ニュースの要点・本質・全体像・背景を多角的に理解できる
- 「なるほど」という納得感
- 自分の仕事への示唆

## ポスト作成フロー

### Step 1: テーマ分析

```
1. このテーマの「本質」は何か？
2. なぜ今このニュースが重要か？（背景・文脈）
3. 読者の仕事にどう関係するか？
4. 既存の常識とどう違うか？（意外性）
5. 歴史や他分野に似た事例はあるか？
```

### Step 2: 型の選択

テーマと伝えたい内容に応じて型を選択。詳細は `references/post-templates.md` 参照。

| 型 | 適用場面 | 負荷 |
|---|---|---|
| 速報＋洞察型 | 最新ニュースを背景付きで解説 | 低〜中 |
| 歴史・文脈型 | 過去の事例から現在を照らす | 中 |
| 概念提唱型 | 新しいフレームワークを提案 | 高 |
| 実践知型 | 自分の経験・観察を共有 | 中 |
| 対比・構造型 | 2つの概念を比較して本質を浮かび上がらせる | 中 |

### Step 3: ポスト作成

**必須要素**
1. **フック**（最初の1-2行で興味を引く）
2. **本質の提示**（「つまり〜」「要するに〜」）
3. **具体例・証拠**
4. **読者への示唆**（「あなたは〜」「これからは〜」）

**文体ルール**
- 断定調と問いかけを混ぜる
- 「〜だと思う」「〜ではないか」で柔らかさを出す
- 専門用語は使っても必ず噛み砕く
- 絵文字は控えめ（使うなら1-2個）

### Step 4: 独自視点の注入

以下の視点を1つ以上入れる：

```
□ プロジェクト推進の視点（作業代替→成果提供）
□ 社会実装の視点（技術→現場への落とし込み）
□ 「普通の人」の視点（エンジニア以外がどう使うか）
□ 経営・組織の視点（導入・推進の課題）
□ 歴史的文脈（過去の技術と比較）
```

## 長文 vs 短文の判断基準

**長文（スレッド含む）が適する場合**
- ニュースに複数の重要ポイントがある
- 背景説明が必要
- 論理展開を見せたい

**短文が適する場合**
- 単一の鋭い洞察
- 実感・感想ベース
- 既に文脈が共有されている話題

**核となるスタンス**
- AIの社会実装を推進する立場
- 技術オタクではなく「使う側」の視点
- 作業代替ではなく「成果提供」「プロジェクト推進」を重視
