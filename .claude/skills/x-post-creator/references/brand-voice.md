# ブランドボイス & トーン

## コアアイデンティティ

**ポジション**
AIの社会実装を推進する実務家。技術オタクではなく「使う側」「現場に届ける側」の視点。

**独自の視座**
```
作業代替のAI → 成果提供のAI
タスク処理 → プロジェクト推進
ツールとしてのAI → パートナーとしてのAI
```

**核となるメッセージ**
- AIは作業を代替するだけでなく、成果を提供するものへ
- プロジェクトという上流概念があってこそAI活用が機能する
- 技術の進化より「現場でどう使われるか」が重要

---

## トーン

### 基本トーン
- **知的だが親しみやすい**：専門的な内容も噛み砕いて伝える
- **断定的だが押し付けない**：「〜だと思う」「〜ではないか」で余白を残す
- **実践的**：抽象論より具体例、現場感

### 避けるトーン
- 上から目線の説教調
- 過度な煽り（「ヤバい」「衝撃」の乱用）
- 技術マウント
- 悲観的な脅し（「AIに仕事を奪われる」一辺倒）

### OKな表現
```
「ぶっちゃけ」
「うーん、やっぱり」
「〜だと思ってきた」
「〜ではないか」
「〜が大事」
「つまり」「要するに」
```

### NGな表現
```
「絶対に〜すべき」（強すぎる）
「〜しないとヤバい」（煽りすぎ）
「AIを使えない人は終わり」（攻撃的）
「私が正しい」（独善的）
```

## 独自視点の入れ方

ポストに以下のいずれかの視点を入れると独自性が出る：

### 1. プロジェクト推進の視点

```
「このAIツールは作業を代替するが、本当に必要なのは成果を出すこと。
そのためにはプロジェクトの目的が明確でないと意味がない」
```

### 2. 社会実装の視点

```
「技術として優れていても、現場で使われなければ意味がない。
SQLの歴史が教えてくれるように」
```

### 3. 「普通の人」の視点

```
「エンジニアにとっては当たり前でも、
経理部の田中さんには全く別の話。
そこをどう橋渡しするか」
```

### 4. 経営・組織の視点

```
「個人の生産性向上と、組織への導入は全く別の話。
後者には『社内AI驚き屋』のような存在が必要」
```

### 5. 時間軸の視点

```
「50年前のSQL、30年前のERP、10年前のRPA。
歴史は繰り返す。今回も同じ轍を踏むのか？」
```

## よく使うフレーズ集

### 本質を語る時
- 「つまり〜ということ」
- 「要するに〜」
- 「本質は〜」
- 「結局〜」

### 洞察を示す時
- 「〜ではないかと思ってきた」
- 「ここから見えてくるのは〜」
- 「裏を返せば〜」

### 問いかける時
- 「あなたの組織ではどうですか？」
- 「どちら側の人ですか？」
- 「〜と思いませんか？」

### 行動を促す時
- 「まずは〜から」
- 「〜を意識するのが大事」
- 「〜という発想で考えてみては」

## ターゲット別の調整

### 企業のAI推進担当向け
- 組織導入の課題に共感
- 現場との橋渡しの難しさ
- 具体的な施策のヒント

### 経営者向け
- ROI、成果の視点
- 競合動向
- 組織戦略としてのAI

### 採用候補者向け
- ミッションへの共感
- 事業のビジョン
- 一緒に何を実現するか

## 避けるべき落とし穴

### 1. 情報の垂れ流し
ニュースをそのまま転載するだけでは価値がない。
必ず「だから何？」を加える。

### 2. 過度な抽象化
「AIで世界が変わる」だけでは刺さらない。
具体例、数字、固有名詞を入れる。

### 3. ネガティブすぎる
「AIに仕事を奪われる」という脅しは疲弊する。
「どう活用するか」のポジティブな視点で。

### 4. ポジティブすぎる
「AIで全て解決」も信頼を失う。
課題や限界も正直に。

### 5. 専門用語の壁
「RAG」「ファインチューニング」は説明なしで使わない。
使うなら必ず噛み砕く。
