# ポストテンプレート詳細

## 1. 速報＋洞察型

最新ニュースを背景・文脈付きで解説。日常的に使える主力の型。

### 構造

```
【フック】ニュースの核心を1行で
　↓
【背景】なぜこれが重要か（2-3行）
　↓
【要点】具体的な内容（箇条書き可）
　↓
【洞察】「つまり〜」「要するに〜」
　↓
【示唆】読者への問いかけ or 行動提案
```

### テンプレート

```
[ニュースの核心を端的に]

【背景】
[なぜ今このニュースが重要か。市場動向、競合状況、技術トレンドなど]

【要点】
・[ポイント1]
・[ポイント2]
・[ポイント3]

つまり、[本質的な意味を一言で]

[読者の仕事への示唆 or 問いかけ]

[ソースURL]
```

### スレッド形式（複数ポイントがある場合）

```
(1/n)
[全体の要約・フック]

(2/n)
【[見出し1]】
[詳細]

(3/n)
【[見出し2]】
[詳細]

...

(n/n)
【まとめ・示唆】
[本質と読者へのメッセージ]
```

## 2. 歴史・文脈型

過去の事例から現在を照らし、本質を浮かび上がらせる。説得力が高い。

### 構造

```
【過去の事例提示】
　↓
【当時の期待・言説】
　↓
【実際どうなったか】
　↓
【現在との類似性】「今、似たようなことが〜」
　↓
【本質の抽出】
　↓
【問いかけ】
```

### テンプレート

```
[過去の技術・事例]って知ってます？

[当時の期待・言説を紹介]と言われていました。

その後どうなったか？

[実際の結末を説明]

今、これと似たようなことが起きてると思いませんか？

[現在の状況を説明]

つまり[本質の抽出]

[問いかけ or 示唆]
```

### 使える過去事例パターン

- SQL → 「誰でもデータにアクセスできる」
- ERP導入ブーム → 「これで業務が効率化される」
- スマホ登場 → 「PCがいらなくなる」
- クラウド → 「自社サーバーが不要に」
- RPA → 「定型業務が自動化される」

## 3. 概念提唱型

新しいフレームワークや名前を提案。バズりやすいが負荷高め。

### 構造

```
【概念名の提示】「〜が重要」
　↓
【背景・課題】なぜその概念が必要か
　↓
【定義・説明】その概念とは何か
　↓
【メカニズム】なぜそれが機能するか
　↓
【具体例】
　↓
【結論・行動提案】
```

### テンプレート

```
[領域]には「[概念名]」が重要なのではと思ってきた

[背景となる課題・現状]

そこで[概念名]が重要になってくる。

[概念名]は[定義・説明]

すると、
[メカニズムの説明]
→[結果・効果]

だから[領域]で[概念名]を[どうする]のが重要
```

### 概念名のパターン

- 「社内AI驚き屋」（役割＋特徴）
- 「プロジェクト推進AI」（対象＋機能）
- 「成果提供AI」（価値＋主体）

## 4. 実践知型

自分の経験・観察から得た知見を共有。短めで端的。

### 構造

```
【観察・気づき】
　↓
【具体例】
　↓
【示唆】
```

### テンプレート

```
[観察・気づきを端的に]

・[具体例1]
・[具体例2]
・[具体例3]

[だから〜/つまり〜]
```

### 短文パターン

```
ぶっちゃけ[主張]

[理由・根拠]

[結論]
```

```
うーん、やっぱり[結論]

[比較や理由]

[補足]
```

---

## 5. 対比・構造型

2つの概念を比較して本質を浮かび上がらせる。

### 構造

```
【比較対象の提示】
　↓
【A の特徴】
　↓
【B の特徴】
　↓
【本質的な違い】
　↓
【示唆・結論】
```

### テンプレート

```
[対象]のモデル選び。[A] vs [B]編

○[A]
　・[特徴1]
　・[特徴2]
　・[特徴3]

○[B]
　・[特徴1]
　・[特徴2]
　・[特徴3]

・結論
　・[本質的な違い・使い分けの指針]
```

## フックのパターン集

### 問いかけ型
- 「〜って知ってます？」
- 「〜と思いませんか？」
- 「なぜ〜なのか？」

### 断定型
- 「明らかに〜」
- 「ぶっちゃけ〜」
- 「〜が重要」

### 速報型
- 「速報：〜」
- 「📕速報：〜」
- 「〜が判明」

### 逆説型
- 「〜と言われていたが、実は〜」
- 「〜ではない。〜だ」

### 共感型
- 「〜ありませんか？」
- 「〜な人、多いと思う」

---

## 締めのパターン集

### 問いかけ型
- 「あなたはどちら側の人ですか？」
- 「あなたの組織ではどうですか？」

### 行動提案型
- 「まずは〜から始めてみては」
- 「〜を意識するのが大事」

### 示唆型
- 「そういう発想でものづくりを考えていくのが大事」
- 「ここから〜が見えてくる」

### 予言型
- 「これから〜になる」
- 「〜の時代が来る」
