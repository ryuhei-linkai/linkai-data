# 単価設定ガイドライン

## 人月単価の考え方

### 基本原則

1. **1人月 = 160時間**（8時間 × 20日）を基準
2. **人月単価** = その人を1ヶ月フルで稼働させた場合の費用
3. **実際のコスト** = 人月単価 × 稼働人月

### 単価設定の要素

| 要素 | 影響 |
|------|------|
| 技術レベル | シニアほど高い |
| 専門性 | AI特化は高め |
| 市場相場 | 需給バランス |
| 案件難易度 | 高難度は上乗せ |
| 関係性 | 長期取引は柔軟に |

### 顧客への提示単価

利益率を確保するため、内部コストに対してマークアップ：

```
顧客提示単価 = 内部コスト ÷ (1 - 目標粗利率)

例：内部コスト80万円、目標粗利率40%の場合
   80 ÷ 0.6 = 133万円（顧客提示）
```

## 利益率からの逆算

### 案件見積もり時

```
1. 契約金額を決める
2. 目標粗利率を設定（例：40%）
3. 許容コストを算出: 契約金額 × 0.6
4. 必要工数を見積もる
5. 許容コスト ÷ 必要工数 = 許容人月単価
6. 実際の人月単価と比較 → GO/NO GO判断
```

### 例

```
契約金額: 300万円
目標粗利率: 40%
許容コスト: 180万円
必要工数: 3人月（見積もり）
許容人月単価: 60万円

→ 人月60万円以下のリソースで回せるか？
→ 泉谷（80万円）だと赤字、桑島（30万円）なら黒字
→ 混成チームで調整
```
