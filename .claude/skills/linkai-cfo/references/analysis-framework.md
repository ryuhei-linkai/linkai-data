# 経営分析フレームワーク

## 1. ランウェイ分析

### 基本計算
```
ランウェイ（月） = 現預金残高 ÷ 月次バーンレート
```

### バーンレート算出
- **グロスバーンレート**: 月間総支出
- **ネットバーンレート**: 月間支出 - 月間収入

スタートアップでは**ネットバーンレート**を使用。

### ランウェイの目安
| ランウェイ | 状態 | アクション |
|-----------|------|-----------|
| 12ヶ月以上 | 安全 | 成長投資可能 |
| 6-12ヶ月 | 注意 | 調達準備開始 |
| 3-6ヶ月 | 危険 | 緊急調達 or コスト削減 |
| 3ヶ月未満 | 緊急 | 即時対応必須 |

### シナリオ分析
- **楽観**: 売上20%増、コスト維持
- **現状維持**: 現在のトレンド継続
- **悲観**: 大口顧客離脱、売上30%減

## 2. 収益性分析

### 粗利率（サービス別）
```
粗利率 = (売上 - 直接原価) ÷ 売上 × 100
```

受託開発の場合：
- 直接原価 = 外注費 + 直接人件費
- 目標粗利率: 40-60%

### 営業利益率
```
営業利益率 = 営業利益 ÷ 売上 × 100
```

スタートアップ初期は赤字が普通だが、トレンドを見る。

### 損益分岐点
```
損益分岐点売上 = 固定費 ÷ 粗利率
```

## 3. 顧客分析

### 顧客集中度
```
上位N社依存度 = 上位N社売上 ÷ 総売上 × 100
```

| 依存度 | リスク評価 |
|--------|-----------|
| 1社50%超 | 極めて高リスク |
| 1社30%超 | 高リスク |
| 上位3社70%超 | 要注意 |
| 分散型 | 健全 |

### 顧客LTV
```
LTV = 月額売上 × 継続月数
```

継続案件 vs スポット案件の比率も重要。

## 4. コスト分析

### 固定費 vs 変動費

**固定費**（売上に関係なく発生）:
- 役員報酬
- オフィス賃料
- SaaS月額費用
- 法定福利費
- 会費

**変動費**（売上に連動）:
- 外注費
- 広告宣伝費
- 旅費交通費
- 交際費

### 固定費率
```
固定費率 = 固定費 ÷ 総コスト × 100
```

高すぎると売上減少時のダメージ大。

### SaaS支出の適正性
月間SaaS支出が売上の5%を超えていないか確認。

## 5. キャッシュフロー分析

### 入金サイクル
- 請求書発行から入金までの日数
- 売掛金の回収状況

### 支払サイクル
- 大型支払いの時期（税金、保険、年払い）
- 買掛金の支払い条件

### 運転資金
```
必要運転資金 = 売掛金 + 棚卸資産 - 買掛金
```

## 6. 投資判断フレームワーク

### 採用判断
```
採用コスト = 給与 + 社会保険料(約15%) + 採用費
回収期間 = 採用コスト ÷ 期待する追加売上
```

- 回収期間6ヶ月以内: GO
- 回収期間12ヶ月以内: 慎重に検討
- 回収期間12ヶ月超: 見送り検討

### ツール投資判断
```
ROI = (コスト削減効果 or 売上増加) ÷ ツール費用
```

ROI 3倍以上を目安。

### 広告投資判断
```
CAC（顧客獲得単価） = 広告費 ÷ 新規顧客数
LTV/CAC比 = 顧客LTV ÷ CAC
```

LTV/CAC比 3倍以上が目安。

## 7. 調達判断フレームワーク

### 調達タイミング
- ランウェイ6ヶ月を切る前に動く
- 調達活動に3-6ヶ月かかることを考慮
- 実質的には「ランウェイ12ヶ月」時点で準備開始

### 調達金額の目安
```
必要調達額 = (月次バーンレート × 目標ランウェイ) - 現預金
```

目標ランウェイは18-24ヶ月が一般的。

### 調達手段
1. **エクイティ**（株式発行）: 希薄化あり、返済不要
2. **デット**（借入）: 希薄化なし、返済必要
3. **補助金・助成金**: 返済不要、手続き煩雑
4. **売上増加**: 最も健全

## 8. 経営指標ダッシュボード

毎月確認すべき指標：

| 指標 | 計算式 | 目安 |
|------|--------|------|
| ランウェイ | 現預金÷バーンレート | 6ヶ月以上 |
| 月次売上 | - | 前月比・前年比 |
| 粗利率 | 粗利÷売上 | 40%以上 |
| 顧客依存度 | 上位3社÷総売上 | 70%未満 |
| 固定費率 | 固定費÷総コスト | 状況による |
| SaaS費用率 | SaaS÷売上 | 5%未満 |
